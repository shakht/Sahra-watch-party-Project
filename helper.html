Send a movie to Sahra

This free helper reads Albox movie links through your own connection. It doesn’t send your cookies or account details to Sahra.

  1. On desktop, drag Send to Sahra to your bookmarks bar.
  2. On mobile, bookmark this page, edit that bookmark, and replace its URL with the code below. Keep the javascript: prefix.
  3. Open an Albox movie playback page, then run the saved bookmark. On some mobile browsers, type the bookmark name in the address bar and select it.
  4. Tap “Copy movie details”. Return to Sahra, paste into Controls → Video link, press Load, and choose a quality.

Mobile bookmarklets are browser-dependent. If your browser blocks it, this helper cannot run there. Friends still need a connection that can access Albox’s video servers.
